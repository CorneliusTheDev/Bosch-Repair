## Error Code F – No Compatible Cookware Detected (Induction)

### What Does Monogram Induction Cooktop Error Code F Mean?

The F error code on a Monogram induction cooktop indicates that **no compatible (induction-capable) cookware has been detected on the cooking zone**. Unlike gas or electric radiant cooktops that heat a surface directly, induction cooktops work by generating an electromagnetic field that heats only ferromagnetic cookware placed directly on the glass surface.

When you activate a cooking zone on your Monogram induction cooktop, it searches for a compatible magnetic pot or pan. If no cookware is placed on the zone, if the cookware is not centered properly, or if the cookware is not induction-compatible, the cooktop cannot complete the electromagnetic circuit and displays the F code.

This is not technically a malfunction — it is a normal status indicator. However, persistent F errors when cookware is present can indicate a sensor problem.

### Common Causes of the F Error Code

- **No cookware placed on the zone** – The cooking zone was activated without placing a pot or pan on it first.
- **Non-induction-compatible cookware** – Aluminum, copper, glass, ceramic, and some stainless steel pots and pans are not induction-compatible. Only ferromagnetic materials (cast iron, magnetic stainless steel) work on induction cooktops.
- **Cookware not centered** – The pan must be positioned over the center of the cooking zone's induction coil. A pan offset to one side may not be fully detected.
- **Cookware too small** – Each cooking zone has a minimum cookware diameter requirement. A small saucepan on a large cooking zone may not trigger the induction sensors.
- **Dirty or cracked cooktop surface** – Thick buildup of food residue under the pan can reduce detection performance in some cases.

### How to Troubleshoot the F Error Code

1. **Check cookware compatibility** – Test your cookware with a magnet. If a magnet sticks firmly to the bottom of the pot or pan, it is induction-compatible. If the magnet does not stick or sticks very weakly, the cookware is not suitable for induction cooking.
2. **Center the cookware** – Position the pot or pan directly over the center of the induction zone, ensuring the base of the cookware fully covers the zone's sensing area.
3. **Use the correct size cookware** – Match the pot or pan size to the cooking zone size. Consult your Monogram cooktop owner's manual for minimum cookware diameter requirements per zone.
4. **Clean the cooktop surface** – Clean the glass surface under the cookware area to remove any food residue.
5. **Test with a known-compatible pan** – Try a cast iron skillet or a pot with a confirmed magnetic base to isolate whether the issue is the cookware or the cooktop.

### When to Call a Professional

If the F code appears consistently with confirmed induction-compatible, properly sized, and centered cookware, the induction coil sensor may have failed. Contact our Monogram cooktop repair team for professional induction sensor diagnosis and repair using factory-certified Monogram parts.

## Error Code F1 – Stuck Touch Pad (Cooktop)

**Page URL:** `/error-codes/cooktop/f1-stuck-touch-pad/`

**SEO Title:** Monogram Cooktop Error Code F1 – Stuck Touch Pad | Causes & Fixes

### What Does Monogram Cooktop Error Code F1 Mean?

The F1 error code on a Monogram cooktop indicates a **stuck touch pad key** — one or more buttons on the touch control panel have been detected in a continuously pressed or shorted state. The cooktop control system interprets this as an indefinitely pressed key and triggers the F1 fault to prevent unintended or uncontrolled cooking zone operation.

This error appears on Monogram induction cooktops and electric cooktops with touch control panels.

### Common Causes of the F1 Error Code

- **Moisture or liquid under the touch control surface** – Cooking condensation, steam, or spills that seep under or around the touch panel can short a key's sensors.
- **Worn or failed touch pad membrane** – The touch-sensitive layer can degrade over time, causing ghost key presses.
- **Failed control board** – The main control board can generate false key-press signals.
- **Heavy object on the touch surface** – Items placed on the cooktop while it is on standby can register as a sustained key press.

### How to Troubleshoot the F1 Error Code

1. **Clear the cooktop surface** – Remove all items, cookware, and cloths from the touch control area.
2. **Power cycle the cooktop** – Turn off the circuit breaker for the cooktop for 60 seconds, then restore power.
3. **Clean the touch panel** – With power off, clean the touch panel surface with a soft damp cloth to remove any grease or food residue around the controls. Dry thoroughly before restoring power.
4. **Check for moisture damage** – If a significant liquid spill occurred near the controls, allow adequate drying time before restarting.

### When to Call a Professional

If the F1 error persists after cleaning and power cycling, the touch pad assembly or control board requires replacement. Contact our Monogram cooktop repair team for professional diagnosis and repair using factory-certified Monogram parts.

## Error Code F7X – Cooling Fan Speed Too Low

**Page URL:** `/error-codes/cooktop/f7x-cooling-fan-speed-too-low/`

**SEO Title:** Monogram Cooktop Error Code F7X – Cooling Fan Speed Too Low | Causes & Fixes

**Meta Description:** Monogram cooktop showing F7X error? This indicates the internal cooling fan speed is too low. Learn causes and how to fix F7X on your Monogram induction cooktop.

**Keywords:** Monogram induction cooktop error code F7X, Monogram cooktop cooling fan failure, Monogram cooktop F7X fix, Monogram induction cooktop overheating, Monogram cooktop repair

---

### What Does Monogram Cooktop Error Code F7X Mean?

The F7X error code (where X is a number) on a Monogram cooktop indicates that the **internal cooling fan speed is too low** — the fan is either running slower than its required minimum speed or has stopped completely. Monogram induction cooktops use internal cooling fans to protect the sensitive electronic components (power inverters, control boards, and induction coils) from overheating. These components generate significant heat during operation and require continuous airflow.

When the control board detects that fan speed is insufficient to provide adequate cooling, it triggers the F7X fault and may reduce or shut down cooktop operation to prevent component damage.

### Common Causes of the F7X Error Code

- **Dirt and debris accumulation around the cooling fan** – Dust, grease, and cooking residue can build up around the fan intake vents (typically on the underside or sides of the cooktop) and restrict airflow, forcing the fan to work harder while delivering less cooling.
- **Faulty cooling fan motor** – The fan motor itself can fail from worn bearings, electrical failure, or physical damage.
- **Blocked ventilation path** – Items placed near the cooktop's ventilation slots or a misfit installation can obstruct airflow.
- **Control board fault** – In rare cases, the control board incorrectly reads fan speed from the tachometer sensor.

### How to Troubleshoot the F7X Error Code

1. **Turn off the cooktop** – Power off the cooktop at the circuit breaker immediately to prevent overheating damage.
2. **Check ventilation clearances** – Ensure there are no objects blocking the cooktop's air intake and exhaust vents. Consult your Monogram cooktop installation guide for required clearances.
3. **Clean around the ventilation vents** – Use a vacuum cleaner to carefully remove dust and debris from the ventilation slots.
4. **Allow the cooktop to cool** – After addressing obstructions, allow the cooktop to cool for 15-20 minutes before restoring power and retesting.
5. **Listen for the fan** – When you power the cooktop on, you should hear the cooling fan running. Silence or unusual rattling suggests a fan problem.

### When to Call a Professional

If the F7X error persists after clearing obstructions and cleaning vents, the cooling fan motor requires inspection and likely replacement. This repair requires accessing the interior of the cooktop. Contact our Monogram cooktop repair team for professional cooling fan diagnosis and replacement using factory-certified Monogram parts.

## Error Code F113 – Cooktop Temperature Sensor Out of Range

**Page URL:** `/error-codes/cooktop/f113-temperature-sensor-out-of-range/`

**SEO Title:** Monogram Cooktop Error Code F113 – Temperature Sensor Out of Range | Causes & Fixes

**Meta Description:** Monogram cooktop showing F113 error? This indicates a temperature sensor reading out of range. Learn causes and how to fix F113 on your Monogram induction or gas cooktop.

**Keywords:** Monogram cooktop error code F113, Monogram cooktop temperature sensor out of range, Monogram cooktop F113 fix, Monogram cooktop RTD sensor, Monogram cooktop repair

---

### What Does Monogram Cooktop Error Code F113 Mean?

The F113 error code on a Monogram cooktop indicates that the **cooktop temperature sensor (RTD) is reading out of the expected range** — either an open circuit (too high resistance, indicating a broken sensor) or a value far outside normal operating parameters. The temperature sensor monitors the cooktop's internal temperature to prevent overheating and protect electronic components.

This error is most commonly seen on Monogram gas cooktops with electronic controls, as well as Monogram induction cooktops.

### Common Causes of the F113 Error Code

- **Open temperature sensor circuit** – The sensor probe itself has developed an open circuit, typically from thermal stress or physical damage.
- **Disconnected sensor wiring** – The wiring harness connecting the sensor to the control board has come loose.
- **Failed RTD sensor** – The resistance temperature detector has reached end of life or was damaged.

### How to Troubleshoot the F113 Error Code

1. **Reset the cooktop** – Turn off the circuit breaker for 60 seconds, then restore power.
2. **Test sensor resistance** – A technician can remove the burner assembly (on gas models) and measure the sensor resistance with a multimeter. The expected resistance is approximately 1100 ohms at room temperature. An open circuit (OL/infinite reading) confirms sensor failure.
3. **Check wiring connections** – Verify the sensor connector is properly seated at the control board.

### When to Call a Professional

The F113 error requires temperature sensor replacement, which involves accessing internal components beneath the cooktop. Contact our Monogram cooktop repair team for professional sensor diagnosis and replacement using factory-certified Monogram parts.

## Error Code F160 – Pan Detection Communication Failure

**Page URL:** `/error-codes/cooktop/f160-pan-detection-communication-failure/`

**SEO Title:** Monogram Induction Cooktop Error Code F160 – Pan Detection Failure | Causes & Fixes

**Meta Description:** Monogram induction cooktop showing F160 error? This indicates a pan detection communication failure. Learn causes and how to fix F160 on your Monogram induction cooktop.

**Keywords:** Monogram induction cooktop error code F160, Monogram cooktop pan detection failure, Monogram cooktop F160 fix, Monogram induction control board, Monogram cooktop repair

---

### What Does Monogram Induction Cooktop Error Code F160 Mean?

The F160 error code on a Monogram induction cooktop indicates a **pan detection communication failure** — the cooktop's control board has lost proper communication with the inductive sensor system that detects whether compatible cookware is present on a cooking zone. This is a hardware-level communication fault between the main control board and the pan-sensing subsystem.

### Common Causes of the F160 Error Code

- **Main control board failure** – The communication interface on the control board that talks to the pan-sensing coils has failed.
- **Inductive sensor wiring failure** – The wiring between the control board and the individual cooking zone induction coils may be damaged or disconnected.
- **Software communication error** – A firmware glitch can cause communication timeouts between the main board and sensor subsystem.
- **Power surge damage** – Voltage spikes can damage the communication circuits on the control board.

### How to Troubleshoot the F160 Error Code

1. **Reset the cooktop** – Turn off the circuit breaker for 5 minutes to allow a full power-down reset of all electronic components.
2. **Retry and observe** – After reset, test whether the F160 code returns immediately or only under certain conditions.

### When to Call a Professional

The F160 error almost always requires professional diagnosis and control board replacement with inductive sensor recalibration. Contact our Monogram cooktop repair team for expert induction cooktop repair using factory-certified Monogram parts.

## Error Code F161 – Burner Temperature Sensor Fault / Calibration Required

**SEO Title:** Monogram Cooktop Error Code F161 – Burner Sensor Fault | Causes & Fixes

---

### What Does Monogram Cooktop Error Code F161 Mean?

The F161 error code on a Monogram cooktop indicates a **burner temperature sensor fault or a sensor calibration issue** — the burner's temperature sensor is either providing incorrect readings or requires calibration after component replacement. This error is sometimes seen after a new control board or cooktop component has been installed, as the sensor parameters may need to be re-synchronized with the new control hardware.

### Common Causes of the F161 Error Code

- **Newly installed control board requiring calibration** – After replacing the main control board, the sensor calibration procedure must be completed for the cooktop to operate correctly.
- **Burner temperature sensor fault** – The sensor itself may be providing readings that fall outside the calibrated range.
- **Miscommunication between sensor and control board** – Wiring or connector issues causing unreliable sensor data.

### How to Troubleshoot the F161 Error Code

1. **Complete the calibration procedure** – If a control board was recently replaced, perform the sensor calibration procedure described in the Monogram service manual for your cooktop model. This typically involves a specific button sequence.
2. **Reset the cooktop** – Try a circuit breaker reset for 5 minutes before attempting calibration.
3. **Check sensor connections** – Ensure all sensor wiring connections are secure.

### When to Call a Professional

If calibration was not recently required (no recent service), the F161 error likely indicates a sensor failure that needs professional diagnosis and component replacement.
