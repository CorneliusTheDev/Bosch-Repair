## Error Code F1 – Open Thermal Sensor / Overheating

### What Does Monogram Microwave Error Code F1 Mean?

The F1 error code on a Monogram microwave indicates that the **thermal sensor (thermistor) has an open circuit or that the microwave cavity has experienced excessive heat**. The thermal sensor continuously monitors the internal temperature of the microwave's magnetron and cavity. If the temperature exceeds safe limits, the sensor circuit opens as a safety mechanism, or the sensor itself can fail open from heat damage.

When F1 appears, the microwave will typically stop all cooking operations and will not respond to cooking commands until the error is resolved.

This error code is seen on Monogram over-the-range microwaves, built-in microwave ovens, and speed oven (combination microwave/convection) models.

### Common Causes of the F1 Error Code

- **Excessive heat in the microwave cavity** – Running the microwave empty, operating it at maximum power for extended periods, or using the microwave immediately after heavy cooking can raise cavity temperature to levels that trigger the thermal sensor.
- **Failed thermal sensor (thermistor)** – The thermal sensor's internal element can burn out and develop an open circuit, triggering F1 even at normal operating temperatures.
- **Blocked or insufficient ventilation** – If the microwave's ventilation is restricted (cabinet installation with blocked top vents, dirty grease filters), heat cannot escape properly, causing the cavity to overheat.
- **Magnetron overheating** – The magnetron (the component that generates microwave radiation) generates significant heat. A partially failing magnetron may run at higher-than-normal temperatures.
- **Dirty interior** – Heavy grease and food buildup absorbs microwave energy and re-radiates it as heat, raising cavity temperature.

### How to Troubleshoot the F1 Error Code

1. **Allow the microwave to cool** – Open the microwave door and let it rest for 20-30 minutes. If the error was caused by temporary overheating, the thermal sensor may reset automatically once the temperature drops to safe levels.
2. **Reset the microwave** – After cooling, unplug the microwave for 60 seconds or flip the circuit breaker off and on. Retry operation.
3. **Clean the microwave interior** – Remove all food residue and grease buildup from the interior walls, floor, and ceiling of the cavity with a damp cloth and mild cleaner.
4. **Check the ventilation** – For over-the-range models, clean or replace the grease filter (monthly for heavy cooking use). Ensure the top of the microwave has adequate clearance for venting.
5. **Avoid running the microwave empty** – Never run the microwave with nothing inside — the microwave energy has nowhere to go and is absorbed by the cavity walls, rapidly raising temperature.

### When to Call a Professional

If the F1 error returns after cooling and cleaning, the thermal sensor has likely failed and needs replacement. This repair requires accessing components inside the microwave, including the potentially high-voltage capacitor. Microwave repairs should only be performed by qualified technicians due to the risk of stored electrical charge. Contact our Monogram microwave repair team for professional thermal sensor replacement using factory-certified Monogram parts.

## Error Code F2 – Shorted Thermal Sensor

### What Does Monogram Microwave Error Code F2 Mean?

The F2 error code on a Monogram microwave indicates that the **thermal sensor is shorted** — the sensor's resistance reading is near zero, far below the normal operating range. A shorted thermal sensor sends a false "very low temperature" signal to the control board, which may cause the microwave to run heating continuously in an attempt to reach a temperature it thinks hasn't been achieved. The control board detects this abnormal reading and displays F2 as a safety fault.

### Common Causes of the F2 Error Code

- **Shorted thermal sensor element** – The internal resistance element in the thermistor has short-circuited from heat damage, moisture, or component failure.
- **Pinched or damaged sensor wiring** – Wires from the thermal sensor can be pinched against the microwave chassis or have their insulation damaged, creating a direct short to ground.
- **Contamination of sensor connections** – Grease or moisture entering the sensor connector can create a conductive path that mimics a short circuit.

### How to Troubleshoot the F2 Error Code

1. **Reset the microwave** – Unplug for 60 seconds and retry. If F2 immediately returns, the sensor has definitively failed.
2. **Test without cooking** – Confirm that F2 appears at startup, not just during cooking operations.

### When to Call a Professional

The F2 error requires thermal sensor replacement, which involves accessing internal microwave components with dangerous stored electrical charges. This repair should only be performed by a qualified technician. Contact our Monogram microwave repair team for safe and professional thermal sensor replacement.

### What Does Monogram Microwave Error Code F3 Mean?

The F3 error code on a Monogram microwave indicates a **shorted touch pad panel** — the control panel's keypad or membrane has developed a short circuit, causing the control board to receive false or continuous input signals from the panel. This can cause erratic microwave behavior, unresponsive controls, or the microwave failing to start.

### Common Causes of the F3 Error Code

- **Liquid damage to the touch panel** – Splashes or steam condensation entering the touch panel creates short circuits between the panel's conductive layers.
- **Worn touch panel membrane** – Aging conductive layers in the touch panel can degrade and develop shorts between adjacent key circuits.
- **Physical damage to the panel** – Cracking or impact damage to the touch panel glass or membrane.

### How to Troubleshoot the F3 Error Code

1. **Clean around the touch panel** – With the microwave unplugged, gently clean around the control panel edges with a slightly damp cloth to remove grease and residue that may be conducting between key areas.
2. **Allow drying time** – If liquid was recently spilled near the controls, unplug the microwave and allow 24-48 hours to dry before retrying.
3. **Reset the microwave** – Unplug for 60 seconds and retry.

### When to Call a Professional

If the F3 error persists, the touch pad panel assembly requires replacement. Contact our Monogram microwave repair team for professional touch pad replacement using factory-certified Monogram parts.

### What Does Monogram Microwave Error Code F4 Mean?

The F4 error code on a Monogram microwave indicates an **open humidity sensor circuit**. Monogram microwaves equipped with automatic (sensor) cooking feature use a humidity sensor to detect moisture levels in steam released from food. The sensor allows the microwave to automatically determine when food is properly cooked without requiring you to set a specific time. An open circuit in the humidity sensor means the control board receives no signal from the sensor.

### Common Causes of the F4 Error Code

- **Failed humidity sensor** – The humidity sensor element has developed an open circuit from heat exposure or component aging.
- **Disconnected sensor wiring** – The wiring from the humidity sensor to the control board has come loose.
- **Food residue on the sensor** – Heavy grease or food buildup on the sensor surface can interfere with its operation.

### How to Troubleshoot the F4 Error Code

1. **Clean the sensor area** – The humidity sensor is typically a small device visible inside the microwave cavity. With the microwave unplugged, gently clean the sensor surface and surrounding area with a damp cloth.
2. **Reset the microwave** – Unplug for 60 seconds and retry. Use sensor cooking (Auto Cook) and see if F4 appears.
3. **Use manual cooking** – If the F4 only appears during auto/sensor cooking programs, you can temporarily use timed manual cooking to continue using the microwave while awaiting repair.

### When to Call a Professional

If F4 persists after cleaning, the humidity sensor requires replacement. Contact our Monogram microwave repair team for professional humidity sensor replacement using factory-certified Monogram parts.

### What Does Monogram Microwave Error Code F5 Mean?

The F5 error code on a Monogram microwave indicates a **shorted humidity sensor** — the opposite of F4. Where F4 means the sensor circuit is open (broken), F5 means the sensor resistance is near zero (shorted). Both conditions prevent the humidity sensor from providing accurate readings for automatic cooking programs.

### Common Causes of the F5 Error Code

- **Shorted humidity sensor element** – Internal failure of the sensor's resistive element.
- **Moisture or condensation on sensor contacts** – In rare cases, heavy steam condensation on sensor connections can cause a temporary short.
- **Damaged sensor wiring creating a short** – Wires routed near sharp edges can have insulation damaged, creating a direct short circuit.

### How to Troubleshoot the F5 Error Code

1. **Allow drying** – If the microwave was recently exposed to very high-steam cooking (steaming vegetables, etc.), allow the interior to dry out with the door open for an hour before retesting.
2. **Reset the microwave** – Unplug for 60 seconds and retry. If F5 immediately returns, the sensor has failed.

### When to Call a Professional

The F5 error requires humidity sensor replacement by a qualified technician. Contact our Monogram microwave repair team for professional repair using factory-certified Monogram parts.

## Error Code F6 – Shorted Temperature Probe

### What Does Monogram Microwave Error Code F6 Mean?

The F6 error code on a Monogram microwave indicates that the **temperature probe (meat probe) is shorted**. Monogram microwaves equipped with probe cooking functionality allow you to insert a temperature probe into food to monitor its internal temperature during cooking. A shorted probe sends a false near-zero resistance reading to the control board.

### Common Causes of the F6 Error Code

- **Damaged temperature probe** – The probe cable may have been pinched by the microwave door or damaged by heat, creating an internal short.
- **Dirty probe connector receptacle** – Grease or food debris in the probe port creates a conductive short between contacts.
- **Failed probe element** – Internal failure of the probe's resistance element.

### How to Troubleshoot the F6 Error Code

1. **Remove the probe** – If a probe is inserted, remove it. The F6 error should clear immediately if the probe itself was shorted.
2. **Clean the probe port** – With the microwave unplugged, clean the probe receptacle with a dry cotton swab.
3. **Inspect the probe** – Check the probe cable for damage. Test by inserting the probe in a glass of ice water — a functioning probe should read approximately 32°F (0°C).
4. **Reset without probe** – Reset and run the microwave without the probe inserted to confirm normal operation.

### When to Call a Professional

If F6 appears with no probe inserted, the probe port or associated wiring may be damaged and requires professional repair. Contact our Monogram microwave repair team for diagnosis and repair using factory-certified Monogram parts.

## Error Code PF / 888 / 8888 – Power Failure or Display Reset

**Page URL:** `/error-codes/microwave/pf-power-failure-display-reset/`

**SEO Title:** Monogram Microwave Error Code PF / 888 – Power Failure | Causes & Fixes

**Meta Description:** Monogram microwave showing PF, 888, or 8888? This indicates a power failure or initial display reset. Learn how to clear these codes on your Monogram microwave.

**Keywords:** Monogram microwave error code PF, Monogram microwave 888 display, Monogram microwave power failure, Monogram microwave reset, Monogram microwave repair

---

### What Does Monogram Microwave Error Code PF or 888 Mean?

The PF, 888, or 8888 display on a Monogram microwave is **not an error code indicating a malfunction** — these codes appear after the initial installation of a new microwave or after a power interruption (power outage, circuit breaker trip, or unplugging). They indicate that the microwave's memory has been cleared and the clock needs to be reset.

- **PF** = Power Failure
- **888** or **8888** = Display test pattern shown after initial power-up

### How to Clear PF / 888 / 8888

1. **Press CLEAR or CANCEL** – On most Monogram microwave models, pressing the CLEAR or CANCEL button once clears the PF or 888 display.
2. **Set the clock** – After clearing, set the correct time using the Clock setting button.
3. **Restore after power outage** – If the display appeared after a power outage, simply press CLEAR and reset your clock.

No professional service is required for PF, 888, or 8888 display codes. These are normal post-power-interruption displays.

### What Does Monogram Microwave Error Code 18 Mean?

The error code 18 (sometimes displayed as "Power Watch") on a Monogram microwave indicates an **electronic control issue**. This error signals that the microwave's control board has detected an internal electronic fault that prevents normal operation. Unlike PF or 888 which are informational, error 18 typically indicates a hardware problem that requires professional service.

### Common Causes of the Error Code 18

- **Main control board failure** – A failed capacitor, relay, or processor component on the main control board.
- **Power surge damage** – Voltage spikes damaging the control board's electronic circuits.
- **Overheating of control electronics** – Inadequate ventilation causing the control board to overheat.

### How to Troubleshoot Error Code 18

1. **Reset the microwave** – Unplug for 5 minutes (longer than a standard reset), then restore power. A temporary electronic glitch may clear.
2. **Check ventilation** – Ensure the microwave vents are clear and the installation has adequate air clearance.
3. **If the error returns** – Contact professional service.
